# FilmRank

> Часть портфолио: [сайт-портфолио](https://auryxn.github.io/site-admin/) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Личный рейтинг фильмов и сериалов: свайпы в стиле Tinder + ранжирование на дуэлях.

## Что это

FilmRank помогает ответить на простой, но мучительный вопрос: **какие фильмы я
люблю больше всего и в каком порядке?** Вместо того чтобы выставлять оценки
звёздочками (которые быстро теряют смысл), вы сравниваете фильмы попарно —
движок сам строит точный рейтинг от лучшего к худшему.

Сначала вы быстро свайпаете карточки из каталога TMDB: смотрел / не смотрел /
хочу посмотреть. Затем начинаются **дуэли**: приложение показывает два
просмотренных фильма рядом, а вы выбираете, какой лучше. Каждый ответ
уточняет позицию фильма в общем списке.

Это личный инструмент (без аккаунтов и сервера): всё состояние хранится локально
в браузере. Интерфейс mobile-first и в тёмной теме — рассчитан на телефон, но
работает и мышью.

## Возможности

- **Свайп-колода** — по одной карточке из каталога TMDB (микс популярных,
  топовых и discover-фильмов, ~60–100 штук):
  - **влево = «смотрел»** → фильм попадает в пул ранжирования;
  - **вправо = «не смотрел»**;
  - **вверх = «хочу посмотреть»** → в список желаний;
  - кнопка **«не помню»**.
  - Работает и жестом (drag + release через framer-motion), и кнопками —
    мышью и пальцем.
- **Список** — «хочу посмотреть» (можно отметить просмотренным или удалить).
- **Смотрено** — все фильмы со свайпом «смотрел».
- **Дуэли** — две карточки рядом: **A лучше / B лучше / Равны / Не помню**.
- **Рейтинг** — упорядоченный список (место, постер, название) и **tier-список**
  (S / A / B / C / D / F).
- **Вкус (Taste)** — статистика предпочтений по жанрам, десятилетиям, режиссёрам.
- **Экспорт** — копирование топа в буфер обмена и Web Share API.
- **Импорт** — вставить JSON с id просмотренных (`{"watched":[603,27205]}`) или
  загрузить `.json`-файл.
- **Сброс** — кнопка в настройках (⚙ в шапке).

## Стек

- **Vite + React 19**
- **framer-motion** — жесты и анимации
- **axios** — запросы к TMDB

Ключ TMDB кладётся в `.env` как `VITE_TMDB_KEY` (читается только через
`import.meta.env.VITE_TMDB_KEY`). **Не коммитьте `.env`.**

```bash
npm install
npm run dev            # http://localhost:5173
npm run dev -- --port 5188 --host 0.0.0.0   # на другом порту / для телефона
npm run build          # прод-сборка в dist/
npm run preview        # предпросмотр сборки
npm run lint           # oxlint
```

## Как работает алгоритм ранжирования (`src/engine/rank.js`)

Движок — чистый модуль без импортов React. Он держит **упорядоченный список**
просмотренных фильмов (от лучшего к худшему) и вставляет каждый новый фильм
через **бинарную вставку**.

1. Новый фильм ставится в очередь (`queue`). Когда очередь не пуста и нет
   активной вставки — стартует новая задача (`pending`).
2. Позиция ищется **бинарным поиском**: окно `[lo, hi)` сужается вдвое на
   каждом ответе.
3. На каждом шаге вопрос: «Новый фильм лучше, чем опора в середине окна?»
   - **A (новый лучше)** → окно `[lo, mid)`;
   - **B (опора лучше)** → окно `[mid+1, hi)`;
   - **Равны** → вставка сразу после опоры;
   - **Не помню** → задача сбрасывается, фильм возвращается в очередь, опора
     запоминается.
4. Когда окно сжалось (`lo >= hi`), фильм встаёт на позицию `lo`.

Итого для `n` фильмов нужно **≈ n·log₂n** сравнений вместо `n²` при
round-robin. Для 25 фильмов это ~87 ответов вместо 300+.

### Публичный API движка

| Функция | Назначение |
|---|---|
| `createState()` | пустое состояние |
| `addMovie` / `addMovies` | добавить фильм(ы) в пул |
| `removeMovie(state, id)` | убрать фильм |
| `nextComparison(state, lookup)` | следующая пара для дуэли (или `null`) |
| `resolveDuel(state, 'a'\|'b'\|'tie'\|'unsure')` | ответить на дуэль |
| `pendingCount(state)` | сколько вставок в работе/очереди |
| `orderedMovies(state, lookup)` | список объектов по порядку |
| `tierBuckets(state, lookup)` | разбивка по тирам S..F |
| `rankText(state, lookup, limit)` | текстовый топ для экспорта |
| `serialize` / `deserialize` | сохранение / загрузка |

## Структура проекта

```
src/
  api/tmdb.js          клиент TMDB (axios), нормализация, сборка каталога
  engine/rank.js       движок ранжирования (чистый модуль)
  storage.js           обёртка над localStorage
  store.jsx            React-контекст: состояние + действия
  components/Poster.jsx
  screens/
    SwipeScreen.jsx       свайп-колода
    WatchlistScreen.jsx   «хочу посмотреть»
    WatchedScreen.jsx     «смотрено»
    RankScreen.jsx        дуэли
    RankingsScreen.jsx    рейтинг + тиры + импорт
    TasteScreen.jsx       статистика вкуса
    SettingsScreen.jsx    статистика, импорт, сброс
  App.jsx              оболочка + нижняя навигация
  index.css            тёмная mobile-first тема
```

Всё состояние хранится одним ключом `filmrank:v1` (каталог, позиция свайпа,
смотрел/список, состояние движка) — сброс = удаление ключа.
